# InventoryMgmtWithJSTL
 j2ee lab 7<br>
The project uses the JSP Standard Tag Library (JSTL) to perform common tasks such as iterating over lists, displaying text, and handling date and time. With a custom tag to display a copyright message. The goal is to build a simple inventory page that showcases the usage of both standard and custom tags in JSP.

# How to Run
Copy the repository to local, then open with Eclipse. Run the project in Tomcat V10 server. Use url: http://localhost:8080/InventoryMgmtWithJSTL/inventory
